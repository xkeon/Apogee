# Apogee Launcher

macOS 的全屏应用启动器：分页网格、拖动整理、文件夹、拼音搜索、翻页特效。

这个仓库只用来发布安装包。

## 下载

[下载最新版 Apogee.dmg](https://github.com/xkeon/Apogee/releases/latest/download/Apogee.dmg)

需要 macOS 26 或更新版本，Apple 芯片和 Intel 芯片的 Mac 都能用。安装包已经过 Apple 公证。

## 安装

1. 打开 Apogee.dmg，把 Apogee 拖进「应用程序」。
2. 打开 Apogee，系统询问时点「打开」。
3. 设置在「系统设置」侧边栏最底部（第一次需要重开一次系统设置）。
